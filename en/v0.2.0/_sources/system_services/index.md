# System Services

:::{note} Document Status: PLANNED — Content for this module has not yet been written
:::

The System Services module will cover the high-level system service components provided by UniSDK, including:

- Task scheduling and event handling
- Memory management
- Logging system (Debug Print)
- System initialization framework

## Currently Available Components

| Component | API | Description |
|------|-----|------|
| System Initialization | `tlk_init.h` | Modular initialization framework |
| Main Loop | `tlk_loop.h` | Event-driven main loop |
| Delay/Sleep | `tlk_sleep.h` | `tlk_sleep_ms()` / `tlk_sleep_us()` |
| Time Management | `tlk_time.h` | Timestamps and timers |

Detailed documentation will be added later. PR contributions are welcome.
