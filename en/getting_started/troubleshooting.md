# Troubleshooting

## Environment Issues

### TELINK_TOOLCHAIN_PATH Not Found

**Error Message**: `Error: TELINK_TOOLCHAIN_PATH environment variable not set`

**Solution**:

```bash
# Linux/macOS
export TELINK_TOOLCHAIN_PATH=/path/to/toolchain

# Windows CMD
set TELINK_TOOLCHAIN_PATH=path\to\toolchain

# Windows PowerShell
$env:TELINK_TOOLCHAIN_PATH="path\to\toolchain"
```

### CMake Configuration Failed

**Solution**:

1. Check CMake version (requires >= 3.20.0)
2. Clear old build cache and retry:
   ```bash
   west tl-build --clean
   ```
3. Verify all dependencies are installed correctly

### Python Dependency Installation Failed

**Solution**:

- Check network connectivity
- Verify the virtual environment is activated (the terminal prompt should have a `(.venv)` prefix)
- Configure a proxy (if needed): `pip install --proxy http://proxy:port -r requirements.txt`

### west init -l Reports "already initialized"

**Cause**: The `ZEPHYR_BASE` environment variable points to a Zephyr workspace containing a `.west` directory

**Solution**:

```bash
# Linux/macOS
unset ZEPHYR_BASE && west init -l

# Windows PowerShell
Remove-Item Env:ZEPHYR_BASE; west init -l
```

## Build Issues

### Compilation Error

**Solution**:

1. Check code syntax
2. Verify chip and board configuration is correct
3. Perform a full clean and retry:
   ```bash
   west tl-build --pristine always
   ```

### Cannot Find pinmux.h

**Solution**:

```bash
# Manually generate pinmux configuration
make pinmux
# or
python -m scripts.pinmux
```

## Menuconfig Issues

### Arrow Keys Not Working in menuconfig Within VS Code (Windows)

**Solution**:

- Use letter keys instead of arrow keys
- Use Windows 11
- Use CMD instead of PowerShell for related operations
- Fall back to an older version of VS Code

## Environment Variable Issues

### Environment Variables Not Taking Effect After Being Set

**Solution**:

1. Restart the terminal, VS Code, or system
2. Manually check whether the PATH variable contains the correct paths
3. Add environment variables to the user-level PATH

## Other Issues

1. Ensure you are using the latest version of UniSDK
2. Clean the build directory and rebuild: `west tl-build --clean`
3. Check the `setup_log.txt` log file (generated by the Windows one-click setup script)
4. Check system logs for more detailed error information
