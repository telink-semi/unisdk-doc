# TL321X Chip Series

!!! note "Document Status: DRAFT — Detailed specifications to be added. The information below is based on SDK metadata and is subject to update."

## Overview

The TL321X is a RISC-V microcontroller series from Telink, designed for general IoT application scenarios.

## Core Parameters

| Parameter | Value |
|------|-----|
| Core | RISC-V (32-bit) |
| Supported Protocols | BLE |
| Toolchain | `andes-riscv32-v5-gcc14.2` (TL32 ELF MCULIB V5 GCC14.2) |

## Memory

| Region | Size | Start Address |
|------|-----|------|
| ROM | 2048 KB | 0x20000000 |
| IRAM | 96 KB | 0x00068000 |
| DRAM | 32 KB | 0x00080000 |
