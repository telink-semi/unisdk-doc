# clangd Setup Guide for VSCode

## What is clangd?

clangd is a C/C++ language server based on the LLVM/Clang tooling ecosystem.
It provides IDE-like features for editors such as:

- complex macro expansion
- intelligent autocompletion
- go to definition
- find references
- semantic highlighting
- inline diagnostics
- code navigation
- rename refactoring
- hover information

## Why use clangd?

Unlike basic syntax highlighting, clangd actually understands:

- compiler defines
- include directories
- generated headers
- specific flags
- warning configuration

Which is quite important in projects using Kconfig, generated configuration headers, and cross-compilation toolchains.
Without proper compile information, editors often show false errors and broken navigation.
clangd solves this by reading the project compilation database.

## Key Files

### `compile_commands.json`

This is the most important file for clangd.
It is generated by CMake and contains the exact compile commands used for every source file.
clangd reads this file to understand your project correctly.

Example:

```json
[
 {
    "file": "src/main.c",
    "command": "arm-none-eabi-gcc -Iinclude -DDEBUG ...",
    "directory": "/project/build"
 }
]
```

### `.clangd`

Optional project configuration file for clangd.

Typical uses:

- add extra compiler flags
- suppress warnings
- configure indexing behavior
- fix generated include issues

Example:

```yaml
CompileFlags:
  Add:
 - -Wall
 - -Wextra

Diagnostics:
  Suppress:
 - unused-parameter
```

## Installing and setup

1. Open Extensions (Ctrl+Shift+X) and install clangd (publisher - LLVM).
2. Proceed with the download prompt.
3. It is recommended to disable the Microsoft C/C++ IntelliSense engine to avoid conflicts.
   `(Ctrl+Shift+P) -> Preferences: Open Settings (UI) -> Extension -> C/C++ -> IntelliSense`
4. Then set `IntelliSenseEngine` to `disabled`.

## Troubleshooting

### The extension works as expected until I look at the file for another core

**Solution**: build your project targeting the files displayed incorrectly.  
**Explanation**: clangd provides the information based on the current build's `compile_commands.json`, so if you have built your project targeting the TL321X core, it cannot resolve the files that belong to the TL721X core correctly, since they are not included in the build.

### I just rebuilt my project, but I still see the warning in the opened file

**Solution**: enforce the update by editing/saving the file.  
**Explanation**: file indexing happens lazily, and since it is unknown what needs to be updated after a rebuild, you may need to enforce it.
